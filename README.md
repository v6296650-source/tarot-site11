# Тайна Арканов — Сайт по Таро

Тёмный мистический сайт с онлайн-раскладами Таро и админкой.

## Что внутри

- Главная страница с выбором раскладов
- 3 вида раскладов: Три карты, Да/Нет, Кельтский крест (упрощённый)
- Красивые переворачивающиеся карты + толкования
- Страница «О мастере» + форма записи на консультацию
- Админка с паролем (по умолчанию: `tarot2026`)
- SEO: meta-теги, robots.txt, sitemap.xml
- Полностью адаптивный дизайн

## Как открыть локально

Просто откройте файл `index.html` в браузере.

Или запустите простой сервер:

```bash
# Python
python -m http.server 3000

# или Node
npx serve .
```

Затем откройте http://localhost:3000

## Админка

1. Перейдите на `/admin.html`
2. Пароль по умолчанию: **tarot2026**
3. Меняйте тексты и сохраняйте

**Важно:** изменения сохраняются в localStorage браузера. Для постоянного хранения на всех устройствах нужно обновлять файлы на хостинге.

## Бесплатный хостинг

### Вариант 1: Netlify (рекомендую)
1. Зарегистрируйтесь на [netlify.com](https://netlify.com)
2. Перетащите папку `tarot-site` в Netlify Drop
3. Готово! Получите ссылку вида `https://something.netlify.app`

### Вариант 2: Vercel
1. Зарегистрируйтесь на [vercel.com](https://vercel.com)
2. Установите Vercel CLI: `npm i -g vercel`
3. В папке сайта выполните `vercel`

### Вариант 3: GitHub Pages
1. Создайте репозиторий
2. Загрузите файлы
3. В Settings → Pages выберите ветку
